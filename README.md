# La cochera de Nidodo en el navegador

Requiere Node.js. Desde esta carpeta, instalar dependencias una vez con `npm install` y ejecutar `npm start`.

Abrir http://localhost:3000. Para detener el servidor, presionar Ctrl+C en su terminal.

Express sirve la exportación original de Unity desde `La-cochera-exportacion-web`. La primera carga descarga aproximadamente 106 MB. El servidor sólo escucha en esta computadora. Esta prueba local todavía no incluye cuentas, aportes ni restricciones de acceso.
